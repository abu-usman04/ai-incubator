# Diary — 2026-05-29

Participant: Diyorbek
Week 1 — Foundation

## What was done

- Restructured an existing private .NET 10 RAG service into the `AiIncubator` monorepo:
  `src/AiIncubator.Server` (API), `src/AiIncubator.Client` (React), `tests/AiIncubator.Server.Tests`.
- Renamed all namespaces, projects, the solution, and configuration (`Naiton.Rag.Service` →
  `AiIncubator.Server`); removed internal IPs and secrets from `appsettings.json`.
- Grew the text-only RAG API into a document knowledge base:
  - Document upload + text extraction (`.txt`, `.md`) → chunk → embed → store in Qdrant.
  - Knowledge modules that group documents, with a sync endpoint.
  - Chat sessions with message history and source citations, reusing the RAG query pipeline.
- Wired Clerk authentication (JWT bearer validation) with a development fallback so the API
  still runs locally without credentials. Added CORS and string-enum JSON.
- Built the React 19 + Vite + Tailwind client: landing, dashboard, documents, chat, Clerk
  sign-in/up, a typed API layer, and an offline mock mode.
- Added README, architecture doc, CI workflow, and this diary. Backend: 49 tests green; client
  builds clean.

## Problems encountered

- After moving projects into `src/` and `tests/`, the test project's `ProjectReference` path
  broke (it still pointed one level up).
- The machine's NuGet feed is a private mirror — even `api.nuget.org` resolves to it — and it
  only carries non-portable PdfPig builds (`0.1.9-alpha`, `1.7.0-custom`). Adding that dependency
  would make the repo unbuildable for anyone cloning it on a normal network.
- Clerk's `ClerkProvider`/`useAuth` require a publishable key and throw when it is missing, which
  would break local development and tests.
- `tsc -b` failed because the referenced `tsconfig.node.json` was not marked `composite`.

## Solutions

- Fixed the `ProjectReference` to `..\..\src\AiIncubator.Server\AiIncubator.Server.csproj`.
- Shipped a portable `.txt`/`.md` extractor now and left PDF as a documented extension point
  (`DocumentTextExtractor`), to be added on a network with real nuget.org access.
- Added a `DevAuthenticationHandler` fallback scheme selected only when Clerk is unconfigured;
  the client conditionally mounts `ClerkProvider` and treats missing keys as mock mode.
- Set `composite` + `emitDeclarationOnly` in `tsconfig.node.json`.
