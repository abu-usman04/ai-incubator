# Diary — 2026-06-08

Participant: Diyorbek
Week 2 — Quiz Mode, Learning Plan Agent, Telegram Bot

## What was done

- Quiz Mode: domain (`Quiz`, `QuizQuestion`, `QuizAttempt`, `QuizAnswer`), in-memory repos,
  `QuizService` that generates grounded quizzes via GLM tool calling over retrieved chunks, grades
  multiple choice by exact match and short answers via the LLM, plus `QuizController` (generate,
  list, get, start attempt, submit answer with live scoring, get result).
- Learning Plan Agent: domain (`LearningPlan`, `PlanWeek`, `PlanTask`), repo, and
  `LearningPlanService` that calls GLM with a `submit_learning_plan` tool to produce a typed,
  validated multi-week plan grounded in the real module/document catalog. `LearningPlanController`
  generates, lists, gets, and completes tasks.
- Telegram Bot: `Services/Telegram` behind interfaces — chat-link repo, sender (with a no-op when
  disabled), reminder dispatcher + `BackgroundService`, an interactive quiz conversation, and an
  update handler. Long-polling receiver and reminder worker start only when `Telegram:Enabled`.
- Reused existing plumbing: extracted `IQueryService.RetrieveAsync` so quiz generation grounds on
  the vector store; both agents use `IChatCompletionClient.ChatAsync` tool calling.
- Frontend: typed client + mock-mode support, `Quiz.tsx` (one question at a time, live score) and
  `LearningPlan.tsx` (weeks/tasks with progress), wired into routes and the sidebar.
